Coding training material

Suggestion: Work on these questions by yourself in a quiet environment.

There are three sections: basic concepts, a few more difficult programs, and data analysis. You can expect that the exam will contain tasks from each section (of course with a task that you have not seen before).

Basic concepts

Task 1

Consider the following code that describes a function that is supposed to work on a list L of integers:

def f(L):
    n = len(L)
    i = 0
    cnt = 0

    while i < n:
        if L[i] < 0:
            cnt = cnt + 1
        i = i + 1
    return cnt

Part 1

Provide a list L such that f(L) returns 3.

Part 2

Rewrite this code such that the while loop is replaced with a for loop.

Task 2

Consider the following code that describes a function that is supposed to sum up the elements in a list L of integers (1, 2, ...):

def sum(L):
    res = 0
    for x in L:
    res = x
    return res

For example, sum([1, 2, 3]) should return 6.

Part 1

Unfortunately, the code doesn't work correctly. It doesn't even run. Fix the code and make two different calls to the function that demonstrate that the function works as expected.

Part 2

Rewrite the (corrected) function in the first task so that it uses a while loop instead of a for loop to compute the sum of the list elements.

Task 3

Gitte is interested in counting the number of 12 grades that she has received in her studies. She wrote a function count that gets a list L of grades and is supposed to return the number of elements that are 12 in the list. She came up with the following solution:

def count(L):
    result = 0
    for x in L:
        if x == 12:
            result += "1"

For example, count([7, 12, 12, 10, 2, 4, 12]) should return 3, and count([12, 12, 10]) should return 2.

Part 1

Unfortunately, her code doesn't work correctly. It doesn't even run. Fix the code and add two function calls that demonstrate that the function works as expected. There is a TypeError which results in the program not running and Gitte forgot to do something at the end of the function. (So, there are two problems with the code.)

You are not allowed to change the name of the function.

Part 2

Rewrite the (corrected) function in the first task so that it uses a while loop instead of a for loop.

A few more difficult programs

Task 1

Every year, Martin has the same problem: On the one hand, his introduction to programming class has exercises in a number of different rooms; on the other hand, he gets a certain number of TAs that he can hire. Sometimes, there are more rooms than TAs, leaving rooms unstaffed!

He wants to automate the process of reminding the administration that the number of assigned TAs does not suffice to run the exercise sessions. Moreover, if he gets enough TAs, he wants to automatically assign them to rooms.

Part 1

Write a function check_ta_count that takes two arguments: the number of rooms assigned to the exercise session, and the number of tas that he can hire. If tas is at least as large as rooms, then your program should print

Thank you very much for such a generous support.

Otherwise, your program should print

Unfortunately, I need more TAs to run the exercise sessions.

For example, running check_ta_count(11, 11) should print the "Thank you" message, and check_ta_count(6, 2) should print the "Unfortunately, ..." message.

Note: You do not have to care about user input, only the function definition is important.

Part 2

Write a function assign_tas that takes two arguments: the number of rooms and the number of tas. The function prints a suggestion how to assign the TAs to the rooms so that no room is left empty. For example, assign_tas(3, 4) could print:

TA 1 goes to room 1.
TA 2 goes to room 2.
TA 3 goes to room 3.
TA 4 goes to room 3.

You can assume that there are enough TAs so that every room can be staffed with at least one. Each TA has to be assigned to exactly one room. You do not have to provide a solution that balances the number of TAs in each room.

Task 2

You are to implement the software to run a vending machine that sells the energy drink RØMMARGORP. One can is sold for 25 kr, and the customer has to pay with coins with value 1, 2, 5, 10, or 20 kr.

Your program has to have the following behavior:

  1. In the beginning, ask how many cans the customer wants to buy.
  2. Print the amount of money the customer has to pay.
  3. In a loop, let the user pay with a coin until she paid the whole amount. After each iteration, print the current balance. Print an error if there is no such coin available (without updating the balance).
  4. Finally, print how much money the customer paid, how much cans she bought, and how much change she gets. Don't print the change if it is 0.

An example interaction looks like this:

How many cans of RØMMARGORP do you want to buy? 2
This will cost you 50 kr. 
Please insert a coin: 20
You payed 20 kr, you still have to pay 30 kr. 
Please insert a coin: 20
You payed 40 kr, you still have to pay 10 kr.
Please insert a coin: 9
Sorry, there is no 9 kr coin.
Please insert a coin: 20
You payed 60 kr, enjoy your 2 cans of RØMMARGORP. 
Don't forget your change of 10 kr.

Task 3

Write a function next_king(name) that takes the name of a king and returns the name of the next king. We simplify the task assuming no female monarchs and no roman numbering system (we use "10" instead of "X"). The rules are as follows:

  1. After a "Christian" follows a "Frederick" and the other way around.
  2. The number increases from "Frederick" to "Christian", but not the other way around.

For example, next_king("Christian 7") returns "Frederick 7", and next_king("Frederick 10") returns "Christian 11".

You can get up to half the points for this task if you can implement the function such that the number is not taken into account, that means if next_king("Christian") returns "Frederick" and the other way around.

Task 4

You are in charge of implementing the search function for courses in the new learnIT version at ITU. For the following discussion, assume that we defined a list courses = ["introduction to programming", "introduction to machine learning", "advanced statistics"]. You can assume for this task that all strings are in lower-case only.

Part 1

Write an interactive program that repeatedly asks the user to input a course, which is stored in a variable course. If the user does not provide input (by just pressing return/enter), the program should quit. Otherwise, it should either print "This course exists at ITU." (if the course is present in the list courses) or "No such course exists at ITU.".

An example run of your program looks as follows:

Please provide a course: introduction to programming 
This course exists at ITU.
Please provide a course: introduction to market economy
No such course exists at ITU.

Part 2

In this task, you will provide an autocompletion feature to your search. Start with the program you developed, and add the following behavior to your program.

Given the input string course provided by the user, the program prints one of the following four options:

  • if the provided string is empty, quit.
  • if no element in courses starts with the provided string, print an informative message and quit.
  • if there is only a single course in courses that starts with the provided string, the course is printed and the program quits.
  • if there are multiple courses that start with the provided string, print each of them and ask the user for input again.

An example run of your program looks as follows:

Please provide a course: intro
Multiple courses at ITU start like this:
introduction to programming 
introduction to machine learning
Please provide a course: introduction to p
The course you mean is introduction to programming

Task 5

Sushi, Betty's cat, has a very specific vocabulary to express her needs. Betty knows Sushi very well, stores Sushi's vocabulary and its meanings in a dictionary.

Now Betty wants to write a function to print the translation of Sushi's sentences. Each sentence is composed by a collection of words separated by a blank space. If there is a word in the sentence that is not listed in her vocabulary, the function should print the same word, without translation.

Part 1

Write a function translator_word(dictionary, word) that given a dictionary and one word said by Sushi, prints its meaning.

For instance, given the following dictionary

sushi_dict = {'meow': 'I am hungry!', 
    'meeoow': 'I am bored!', 'mmmeow': 'Nap time.', 
    'meoooow': 'Pet me!', 'meooooww': 'Enough!', 
    'meoooooooww': 'How dare you human!'}

translator_word(sushi_dict, 'meow') should print I am hungry! and translator_word(sushi_dict, 'meowowowowow') should print meowowowowow, since this is not a word listed in the dictionary.

Note that your function should work for any dictionary provided with the word, and not only for the one given as an example.

Part 2

Write a function translator(dictionary, sentence) that takes a dictionary and a sentence composed of many words separated by blank spaces and prints its meaning.

For instance, translator(sushi_dict,'mmmeow meoooow') should print Nap time. Pet me!, and translator(sushi_dict,'meoooow prrrr prrrrrrr') should print Pet me! prrrr prrrrrrr.

Data analysis tasks

Task 1

Rasmus traveled a lot through the last years: the file trips.txt summarizes his 10,000 most recent trips. Of course, given this amount of traveling, he cannot remember every single trip. He has asked you to help him out getting an overview of his travel.

Part 1

Write a function has_visited that takes three arguments: the filename of the file that contains his trips, a string country, and a string city. Your function has to return True if Rasmus has visited this particular city in this particular country according to the file storing his trips. It has to return False otherwise.

Part 2

Write a method most_visited that takes a single argument: the filename of the file that contains his trips. The function prints the country that Rasmus has visited most frequently.

As an example, let's assume a file example.txt contains the following lines:

Denmark, Aarhus
Sweden, Malmo
Denmark, Aarhus
Denmark, Skagen
Denmark, Padborg
Spain, Madrid

According to the specification above, has_visited('example.txt', 'Denmark', 'Aarhus') has to return True and has_visited('example.txt', 'Denmark', 'Copenhagen') has to return False. The function most_visited('example.txt') has to print Denmark, because he has visited Denmark 4 times, and Sweden and Spain only once.

Task 2

Denmark's train operator DSB is well known for its punctuality. Still, you want to make sure that you are well prepared for your Christmas trip from Copenhagen to Holstebro.

In the file delays.txt you find a list of train trips from the past. We keep the format simple: each line describes a trip from city A to city B followed by the delay in minutes. For example, the line

Copenhagen Roskilde 3

means that the train from Copenhagen to Roskilde had a delay of 3 minutes. You can assume that city names don't include spaces.

Part 1

Define a function print_trips(filename, start, destination) that prints all lines in filename that start in start and end in destination. At the end, print the average of all the delays.

To compute the average delay, sum up all the entries and divide by the number of trips. Use integer division // to round down to the nearest integer. If no trip exists from start to destination, print "No trip found.".

Part 2

Define a function find_maximum_average_delay(filename) that returns the connection with the maximum average delay among all trips in the file filename.
